# 公开静态审阅器代码审查

本文的对象仅为仓库 `apps/reviewer/` 静态审阅器，不是任何外部站点、工程或后台服务的安全认证。审查关注目录隔离、输入边界、预览状态、备份与异步生命周期；架构及能力范围分别见 [架构](ARCHITECTURE.md) 与 [公开范围](PUBLIC-SCOPE.md)。

## 已实现的防线

- `shared/project-loader.mjs`、`shared/project-schema.mjs` 验证已登记项目、描述及唯一存储键；`shared/resource-url.mjs` 限制资源路径跨目录/来源逃逸。
- `shared/json-budget.mjs` 和 `viewer.mjs` 对 JSON、GLB、图片、顶点与索引设置大小/复杂度边界；未知必需扩展、外部资源和重定向拒绝。
- 浏览器异步读取按项目/数据集与请求代次取消；晚到结果不能写进新选择，预览组件释放 GPU 对象。
- 本地审阅 v2 备份校验身份；精确恢复须完整范围、确认及成功持久化。语义候选只接受受控词表、有证据、当前输入摘要，人工决策与动画验证分开；侧车回导先预检、确认再合并。
- 构建由 `scripts/public-build-inputs.json` 显式列文件；源清单与构建清单分别校验，防止把未经审查的目录当作自动发布输入。

## 保留限制

静态和 CPU 回归不能证明真实 WebGL/GPU 外观、材质一致、用户辅助技术体验或第三方输入无恶意内容；浏览器本地存储不能保证跨标签页事务或抵御同源恶意脚本。JSON/GLB 元数据仍可能含私人路径，应在公开前单独检查。自制演示的正确性不外推到外部目录或其他引擎。

任何新增外部格式、第三方资源、站点服务或权限能力须单独明确授权与测试，不能借静态审阅器现有验证宣称完成。具体测试入口与未验证项记录方式见 [验证说明](VALIDATION.md)。
