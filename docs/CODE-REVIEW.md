# 代码审查、修复与复审

日期：2026-10-25。流程：初审 → 修复 → 独立复审 → 修复复审发现 → 回归检查 → 据实际实现编写文档。生产站点没有因本次仓库工作自动更新；这里描述的是修复后的代码交付。

## 范围与方法

检查了前端控制器、数据适配、资源解析、预览器、状态持久化、导入导出、托管认证边界、HTTP/MCP、增量清单与内容校验、D1/R2 事务、构建及公开分发。使用源代码检查、合成负例、实际 CPU parser、DOM 测试替身、本机 HTTP 和现有资产兼容回归。没有把它称为渗透测试、形式证明或真实 GPU 验收。

## 修复闭环

| 初审问题 | 已实施处理 | 复审重点与结论 |
|---|---|---|
| 同 ID 跨项目备份覆盖 | v2 明确 projectId/datasetId；不匹配拒绝；v1 需确认迁移 | 拒绝跨项目，取消不修改状态 |
| 目录/资源/存储键缺校验 | 独立 project-schema 模块验证身份、唯一性、补充资源及键冲突 | 复审发现补充 dataset 绕过，已补修并重测 |
| 项目根隔离依赖可选 hint | 从每个已验证 descriptor 推导真实资源根 | 嵌套目录且无 hint 的绕过已关闭 |
| 模型和 JSON 无完整输入预算 | 下载、解压、累计 JSON、分片并发、几何/图像预算 | 超限拒绝；重定向禁止且不可被调用参数覆盖 |
| GLB 未知 required extension | 支持集合外明确拒绝，optional 单独提示 | 未把近似 UV 支持宣称完整扩展支持 |
| Python 根外符号链接 | 两种服务器真实路径围栏、隐含文件/目录保护 | 合成 GET/HEAD 攻击请求拒绝 |
| GLB 元数据隐私漏检 | JSON 与 GLB 统一元数据规则 | 重复字段隐藏、非 UTF-8、编码与标点包裹路径均补修 |
| 旧收据绕过新校验 | indexed-static-2；旧收据必须重新验证后条件升级 | 不能无验证重新标记，历史只读版本不受破坏 |
| 托管身份被误当独立认证 | 无显式信任契约默认关闭；固定资源先鉴权；内部回退路径不可直读 | 仅解决错误部署默认开放，真实网关仍是前提 |
| 公共构建依赖私人语料 | 独立白名单静态构建，合成示例，能力清单 | 可重复输出，拒绝输入/输出符号链接；后台不偷渡 |
| 默认测试漏 .mjs 套件 | 聚合入口纳入新增前端/导入/服务器/构建测试 | 复审发现 app npm test 漏套件，已补齐 |
| 可读性与测试脆弱 | 身份/迁移/预算独立模块，规范前端格式化 | 源字符串检查与函数提取改为格式稳健，行为断言保留 |
| 许可与公开范围不明 | MIT；合成样例；私有数据与部署配置排除 | 不把原游戏资产纳入许可证 |

### 第二轮实际发现

复审没有仅确认“测试是绿的”：它额外发现原始 JSON 中被覆盖的重复成员仍保留敏感字节、路径前标点导致漏检、补充资源在主目录校验后插入，以及可选资源根登记造成隔离缺口。实现随后针对这些反例修改，独立复审再次运行后关闭对应发现。

## 仍是产品范围或外部验收的事项

1. 公开静态版不是完整可自托管后台。参考源码缺少私人输入和宿主适配；其公开构建明确禁用该能力，而非用假数据承诺完整服务。
2. 托管身份契约是入口信任声明，不是签名验证。新宿主必须另行实现认证并验证入口行为。
3. 资源预算是明确的输入边界，不是浏览器总堆、GPU 或任意数据集性能保证。
4. 真实浏览器工具在本轮返回运行时不可用；没有完成修复后的真人键鼠、跨浏览器、GPU 像素和音画验收。
5. 全量许可证/依赖漏洞审计和生产渗透测试不在此次已通过结论内。

这些不能通过修改文字或增加测试数宣称关闭。详细执行层级见 VALIDATION.md。
