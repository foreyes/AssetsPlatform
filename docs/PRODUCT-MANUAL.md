# Assets Platform 产品使用手册

## 1. 产品定位与版本边界

Assets Platform 是面向资产审阅的工作台：先查看完整物件，再检查它关联的模型、材质、贴图、动画引用和来源记录，记录选择、结论与备注。它不是游戏运行器、Unity 编辑器、完整资产转换平台或任意项目的一键恢复工具。界面中的“可预览”仅指存在模型供给，不代表该项已完成 GPU 视觉验收，也不代表可以直接导入游戏引擎。

本手册依据 2026-10-25 审查的前端源代码。本仓库独立前端位于 `apps/reviewer/`，托管参考位于 `reference/hosted/`；下文 `app.mjs`、`shared/`、`adapters/` 等路径均相对于独立前端根目录。托管参考实现使用 `review-frontend/shared/` 对应模块。本手册区分两个运行范围：

| 能力 | 独立前端 | 托管平台参考实现 |
|---|---|---|
| 目录切换、搜索、筛选、分页、完整物件/技术资源 | 有 | 有，数据适配器可不同 |
| 浏览器个人选择、审阅结论、备注 | 有 | 有 |
| JSON 备份、CSV 导出、审阅 JSON 导入 | 有 | 有 |
| 自包含 GLB 预览与通用检视风格 | 有，需 WebGL | 取决于格式适配器 |
| 已验证动画侧车数据播放 | 代码有条件支持；随包立方体无动画 | 仅对具备验证记录的资产开放 |
| 身份验证、伙伴共享选择 | 不包含；provider 为空实现 | 依赖站点身份、API 与服务器存储 |
| 原生/专有格式、闭合 glTF、私有对象供给 | 不包含 | 依赖独立适配器、资源供应链与后端 |
| 自动提取 Unity 工程、执行资产脚本 | 不支持 | 不应从预览功能推定支持 |

托管源码参考不是一个可以仅凭静态服务器启动的完整部署。公开仓库不得携带私有资产、真实账户资料、密钥或原站点访问配置。项目自有代码与文档采用 MIT；资产许可独立，不能由“可下载”推定商业游戏素材可再分发。


### 当前修复后的数据保护规则

- 新 JSON 备份为 v2，绑定 projectId 与 datasetId；导入到不同目录会被拒绝，不覆盖记录。
- 旧 v1 文件不能证明目录身份，界面先要求确认属于当前目录；取消不修改状态。带明确不匹配身份的文件不能靠确认绕过。
- 描述文件、目录 ID、补充资源 ID 和存储键在建立页面状态前校验；重复或冲突应修正数据，不静默覆盖。
- 目录与模型请求拒绝重定向；资源必须直接位于已登记的授权根内。
- 下载、JSON 解压、分片和模型都有明确预算；超限不会自动降级为旧图冒充成功。

## 2. 首次运行独立前端

### 环境与启动

需要 Node.js 18 或更新版本，或者 Python 3；3D 需要浏览器可用的 WebGL。独立前端没有 npm 运行依赖。

在独立前端目录打开终端：

```sh
npm start
# 等价：node server.mjs
```

打开终端显示的本机地址，默认 `http://127.0.0.1:8768/`。不需要 `npm install`。端口被占用时可通过 `PORT` 环境变量为 Node 服务指定其他端口。备用命令是 `python3 serve.py`，默认使用 8768 端口，也支持 PORT 环境变量。两种服务均检查真实路径、符号链接和隐含文件边界。

不要直接双击 HTML：`file:` 模式下模块与 JSON 读取受到浏览器限制。两个服务器都是开发用本机静态服务，没有账户管理；不要把它们直接改成公网监听并视为生产安全部署。结束终端进程即停止服务。

### 初次检查

1. 左侧目录选择器中切换两个自制示例目录，确认首页结构一致。
2. 点击立方体查看详情。没有 WebGL 时应显示错误；这不意味着 JSON 目录和本地审阅功能必然不可用。
3. 选择一项，写入备注，刷新页面后检查记录。
4. 先导出完整目录与审阅 JSON，再在同一目录导入测试。
5. 执行 `npm test` 验证文件闭合、身份契约、模型输入和本地服务器边界（需 Python 3）。该命令不是完整浏览器、权限、安全或像素测试。

## 3. 工作区与检索

- **完整物件**：面向使用者的组合对象。物件可以关联多个技术资源，名称与源资源名可以不同。
- **技术资源**：底层模型、材质、贴图、动画、Shader、音频等索引。被收录不等于每种资源都具有独立播放器；材质引用或动画元数据不能冒充真实渲染/播放。
- **我的选择**：当前目录中已勾选的条目。勾选用于整理，不自动改变审阅结论。
- **已审阅**：审阅状态不为 `pending` 的条目。仅写备注而保持“未审阅”不会使其进入该集合。

搜索会匹配名称、稳定 ID、来源字段、描述、标签和已关联资源名称等。搜索不访问未登记目录，也不是远程全网搜索。没有弹窗且焦点不在输入控件时，按 `/` 聚焦搜索框。

类别、审阅状态、预览状态可组合筛选。技术资源视图还可按语义类别筛选；托管适配器可提供额外维度。排序包括推荐、名称、面数和类型。网格/列表使用同一数据与审阅状态；浅色、深色和棋盘仅改变预览背景。分页固定每页 20 项。切换工作区会重置搜索与部分筛选，空结果可用“查看全部素材”恢复。

页面统计分别代表可预览物件、物件总数、资源总数和审阅进度。物件总数不是模型数，资源总数不是已验证预览数。统计说明由启动后的通用 shell 更新，不能根据初始 HTML 占位词判定最终能力。

## 4. 详情与比较

点击物件打开详情。可查看分类、已提供的顶点/三角面数、组成关系、来源信息、技术信息与下载链接。缺失数据应显示未知/未提取，而不是零值或完成状态。若存在来源层级，可展开查看节点以及源禁用标记；显示层级不表示运行时逻辑已恢复。

3D 控制包括拖动旋转、滚轮缩放、方向键旋转、重置相机与线框。详情中的 A/B 渲染比较是在同一物件上比较两个预览风格，支持时同步相机；格式适配器禁止比较时控件禁用。

“并排比较”要求选择 2–4 项，展示各项缩略图和元数据，随后可进入单项详情。它不是四个同时可交互的完整 3D 编辑器。切换物件、关闭详情和页面离开会取消相关请求并释放渲染器；浏览器后台会暂停播放和缩略图工作。

### 渲染方式

| 显示名称 | 用途与边界 |
|---|---|
| 源材质 | 使用模型提供且当前渲染器支持的材质数据，不保证完整原始引擎外观 |
| 白模 | 便于检查几何、轮廓与光照，不改写源模型 |
| 三阶卡通 | 分阶光照检视 |
| 自然柔光 | 通用柔和光照检视 |
| 双阶冷影 / 双阶暖调 | 两组色调与分阶检视 |

默认渲染方式保存于当前目录的浏览器存储键，卡片与详情 A 使用同一默认。更改预览风格不修改磁盘模型，也不移植原游戏 Shader、场景灯光或后处理。历史预设 ID 仅用于兼容，不代表包内存在对应商业素材。

### 独立渲染器支持范围

`viewer.mjs` 是自定义 GLB 解析和 WebGL 绘制实现，不应因配置中的 `kind: "three"` 就推定它使用完整 Three.js GLTFLoader。实际范围包括 GLB 2.0 内嵌二进制、三角形/三角带/三角扇、节点变换、UV0、部分材质纹理、透明模式及经过验证的蒙皮数据。

已知限制：

- 不加载外部贴图；需内嵌 bufferView 或可用的内嵌图片数据。
- Draco、meshopt 必需压缩扩展被拒绝；不是通用完整 glTF 扩展实现。
- 点/线拓扑不显示；形态目标仅显示基础几何，不播放 morph 动画。
- 仅支持 UV0；法线贴图未应用，不能据预览判断全部材质通道准确。
- 骨骼/权重有效性检查不等于运行时 IK、物理、事件或游戏脚本执行。
- 多个复杂对象、大贴图与大量顶点会占用浏览器内存。单模型几何、accessor、图片和下载均有限制，目录 JSON 与分片另有预算，但不能保证任意模型始终安全或流畅。

以上来自 `viewer.mjs` 的解析与诊断逻辑；代码支持不等于此次 GPU 视觉验证通过。

## 5. 动画、效果与验证标签

独立示例没有动画，不能因为界面代码存在时间轴就声称示例可播放。索引适配器只有在配置开启 `verifiedAnimation` 时读取动画和动作目录；界面还检查 `ready` 状态、蒙皮绑定、源曲线、像素验证标记、模型/数据路径以及已验证片段 ID。此处的标记来自数据提供者，本身不是浏览器重新执行了验收。

符合条件的资产可提供播放/暂停、停止、定位、速度、循环和片段选择。源片段、静态姿势、依据指定条件派生的流程以及尚未转换的动画引用不同；引用列表不提供假播放。源曲线或离线约束结果不等于完整引擎运行时。页面隐藏、切换动作/物件和关闭详情会暂停播放。

通用独立入口明确关闭专门的研究、武器专题和特效面板。即使源码保留相关函数，也不应将它们宣传为当前独立版本已启用功能。

## 6. 选择、结论与备注

审阅状态：`pending` 未审阅、`keep` 保留、`check` 待检查、`skip` 暂不用。备注最多 10,000 字符；输入后约 350 ms 保存，正常关闭详情时也会保存。浏览器存储失败会出现提示；当前页面内仍可操作，但关闭前应导出。

本地存储不是账户同步、服务器备份或加密保险箱。同一个 URL 来源、浏览器配置和存储键决定能否看到原记录；换浏览器、换端口、隐私模式、清理站点数据都可能导致看不到旧记录。不要在备注中写密码或访问令牌。

清空选择只移除勾选，不删除审阅结论或源资产。切换目录时保持独立存储依赖每个目录配置不同的 `reviewKey` 和 `renderPreferenceKey`；加载器会检查登记目录之间的存储键冲突。

## 7. 导出、导入与设备迁移

### 三类导出

1. **导出目录**：当前目录全部条目的精简索引与审阅记录。
2. **导出审阅 JSON**：所选条目的索引与所选条目的审阅记录；不是所有未选条目的完整备份。
3. **导出 CSV**：所选条目的表格报告，包含 ID、名称、类型、部分来源字段、几何统计、预览类型、审阅结论和备注。CSV 用于阅读分析，当前不支持从 CSV 恢复审阅。

JSON 含 `format`、`version: 2`、`projectId`、`datasetId`、导出时间、目录版本、范围、`selected`、`reviews`、`assetMetadataOnly: true` 及精简 `assets`。资产索引仅保留 `id/sourceId/name/type/category/modelUrl/metadataUrl` 等字段，不含模型字节、完整依赖或原工程备份。路径可能是当前服务解析后的绝对地址；迁移时仍须另外搬运资产目录，不能把 JSON 当成离线模型包。

### 导入规则

使用“导入审阅记录”选择本产品导出的 JSON。示例限制为 25 MiB；配置可改变上限。导入检查 format、version、projectId、datasetId 与 reviews 结构，仅接受当前目录已知 ID 和合法审阅状态，忽略未知 ID、危险属性名与不合规记录；长备注截断到 10,000 字符。

默认“导入审阅记录”是合并：同 ID 的审阅记录被导入值覆盖，选择集合取并集；不是恢复时自动清空当前数据。若需要完整可回退操作，应先导出当前目录备份。

v2 导入严格检查项目与数据集。旧 v1 需显式确认迁移；请只迁移你能确定所属目录的备份，不用确认跳过明确身份不匹配。

### 精确恢复完整审阅备份（仅独立前端单键本地目录）

若要回到备份时的审阅与选择，而非合并，打开“资源说明”（移动端“来源与边界”），先点“导出目录与审阅记录”保存当前完整备份，再点“精确恢复完整审阅备份（替换）”。选择文件后还有一次替换确认；取消不会更改审阅或选择。没有自动检查点或自动撤销，未另行保存的旧记录被替换后无法恢复。回退方式是用同一入口恢复先前保存的完整备份。

- 仅接受同 `projectId` / `datasetId`、正确 `format`、`version: 2`、`scope: full-catalogue` 的完整备份。所选导出、v1、未知 ID、重复选择、畸形记录、额外审阅字段或超过 10,000 字符的备注均整份拒绝，不静默丢弃或截断。
- 确认后完全替换当前审阅记录和选择；备份未包含的旧记录会删除。合法空备份只有确认后才清空。资产索引、模型文件与渲染偏好不变。
- 仅当 `sharedSelections: false` 且未配置 `selectionStorageKey` 时启用，使审阅和选择能以一次 `localStorage.setItem` 写入同一 `reviewKey`。存储写失败不修改原主存储或内存；写成功才更新界面。
- 文件读取期间切换目录/数据集、离开页面或开始新的导入/恢复，会使旧请求失效，防止旧结果覆盖新状态。此保护不是跨标签页事务：恢复前请关闭其他同目录标签页。

此入口恢复的是审阅状态，不是模型、工程或托管数据库。实际浏览器文件选择器、确认框和 GPU 交互仍需人工验收；自动测试使用合成存储与 DOM 测试替身。

## 8. 为独立前端添加目录

目录维护者需要准备数据文件；终端用户不能把任意 Unity Assets 文件夹拖入网页自动导入。复制示例目录后，至少准备：

```text
my-library/
  project-config.json
  assets/
    catalog.json
    objects-catalog.json
    render-profiles.json
    canopy-rules.json
    object.glb
```

`canopy-rules.json` 是可选配置，缺省使用空规则；即使没有特殊规则，也应提供 `{"version":1,"flatCanopySourceMaterialIds":[]}`。渲染配置文件可为空配置；复制随包有效示例比从零猜测结构更可靠。

根 `project-directory.json` 的 `projects` 登记唯一 `id`、显示 `label`、配置路径 `config`、`assetRoot`，并指定 `defaultProject`。配置中的顶层 `id` 必须等于登记 ID；`assetRoot` 相对配置文件解析，且应与登记根一致。

项目描述文件包含：

- 顶层 `id`、`datasetId`、`assetRoot`、`dataKind: "indexed"`；当前独立 loader 不支持其他 dataKind。
- `renderer` 描述能力；实际 renderer 固定来自可信应用模块，不能通过陌生资产提供 JavaScript。
- `config` 内的 `slug`、`label`、独立存储键、`importFormat`、`exportPrefix`、`defaultProfile`、`compareProfile`、`verifiedAnimation`、`importLimitMiB`、`sharedSelections: false` 和 `capabilities`。
- `typeLabels`、`categoryLabels`、`defaultProfiles` 等呈现配置。

`catalog.json` 的 `assets` 保存技术资源；每项应有唯一稳定 `id`、`name`、`type`，可提供 `category`、`modelUrl`、来源与元数据路径。大目录可用 `assetShards`；分片路径同样经资源解析器。

`objects-catalog.json` 的 `objects` 保存完整物件；每项应有唯一稳定 `id`、`name`、`category`、模型路径，可用 `assetId` 关联技术资源。`assemblyModelUrl` 优先于普通 `modelUrl`，后者可从关联资源回退。一个目录内物件与资源应使用不同 ID，防止 Map 查找和审阅身份碰撞。改显示名称不应改 ID。

模型路径如 `assets/object.glb` 相对该项目根，而不是相对浏览器当前任意目录。路径解析会拒绝遍历、跨目录、未知协议、外部资产请求和未经登记的资源根；外部来源/下载链接需显式登记 HTTPS origin。前端路径约束不是服务器账户权限，公开静态服务器上的文件仍须由部署者决定公开范围。

## 9. 托管共享选择（不属于独立前端）

托管 provider 的身份来自服务器 session，而不是展示昵称。界面先保留本地草稿，点击“发布我的选择”才通过 API 发布给已有伙伴；个人备注不随选择发布。共享清单可刷新、查看、导出 manifest，或将他人条目加入自己的草稿，但不会修改对方清单。

“载入服务器版本”会替换本人本地草稿，有未发布更改时要求确认。发布带有已知 revision，用于服务端冲突检查；具体授权、冲突响应、访问名单和持久化必须通过后端验收，不能只凭前端按钮证明安全。

manifest 是资源交付计划，不是登录凭据，也不是所有资源字节。下载需要使用本人已有权限。浏览器 GLB 不保证 Unity 即插即用；仅标明引擎/管线、依赖、许可证和已验证状态的交付包才能按其说明导入。

## 10. 故障排查与验收

| 现象 | 首先检查 |
|---|---|
| 启动失败/目录读取失败 | 是否用 HTTP；配置 ID 与登记是否相符；四类数据文件是否齐全；路径和 JSON 是否有效 |
| 提示未知项目 | URL 的 project 参数是否在根目录登记；不要放开任意路径来绕过 |
| 列表空白 | 是否有 objects；搜索/筛选是否过窄；不能把请求失败当成空目录成功 |
| 3D 错误但有元数据 | WebGL 是否可用；GLB 是否自包含、未用不支持压缩；查看预览错误与警告 |
| 材质与原引擎不同 | 检查 UV0、内嵌贴图和未实现通道；预览风格不是原 Shader |
