# 产品手册：本地静态资产审阅器

本手册面向已获授权使用静态目录的审阅者。运行 `npm start` 后打开 http://127.0.0.1:8768/；Node.js 最低 18。也可在 `apps/reviewer` 运行 `python3 serve.py`。本地服务只监听环回地址，没有账号系统。示例目录使用本仓库生成的立方体与线性动画，不包含第三方游戏素材。

## 浏览和预览

左栏切换已登记目录；主栏可在物件、技术资源、选择和已审阅视图间切换。关键词、类别、类型、审阅状态和预览条件共同筛选；顶部摘要分开显示全目录与当前匹配数，分页只切分匹配集合。物件与其技术资源有不同 ID，普通模型贴图不自动成为独立物件。

点击卡片打开详情。GLB 材质、中性白模、三阶明暗、柔和中性、冷调双阶和暖调双阶是六种通用浏览器检视方式；它们不更改源 GLB。若资源只有缩略图，界面不得将其称作可核对的独立原图；若原图明确登记为物件，可显示 2D 原图。WebGL 不可用、模型失败或来源未知时保持相应待验证状态。目录切换或关闭详情会取消过期加载。

动画仅在侧车、源轨道、绑定及人工播放证据满足各自条件时开放对应能力；仅有骨骼或动画引用不等于可播放。自制示例的静态 CPU 检查不替代真实浏览器 WebGL 验收，步骤见 [动画示例](ANIMATION-EXAMPLE.md)。

## 选择、备注与备份

卡片可加入本地选择；详情可将审阅状态设为未审阅、保留、待检查或暂不用，并保存最长 10,000 字符的备注。记录默认只在当前浏览器保存，清理浏览器数据可能丢失，故应导出备份。普通导入合并当前身份下的已知 ID；旧版备份需明确确认。单键独立目录可在导出当前完整备份后，通过明确确认执行同项目/数据集的精确替换；这不是模型备份、跨标签页事务或自动撤销。

## 语义标签

展开“语义标签与本地候选审阅”可以按内容分类、用途标签、2D/3D 维度和分层动画事实筛选；同维度多选默认 OR，不同维度为 AND，也可明确使用“全部/任一/排除”。未标注与未知可分别筛选。结果数不替代全目录数。

批量操作需先选择范围：当前结果页、当前匹配集合或当前数据集全目录；确认框显示作用项数。可以导出本地候选输入或侧车，文件可能含来源引用，分享前请检查。Agent 候选仅进入待审，必须人工接受、拒绝或更正；不执行模型调用。已有人工决策的备份经无副作用验证后需再次确认可信来源，取消不更改状态。输入变化只使相关未锁定候选失效；锁定人工决定保留并提示复核。完整协议见 [语义标注契约](SEMANTIC-ANNOTATIONS.md)。

## 导入自己的目录

目录维护者可从自制模板准备 `project-config.json`、物件与资源目录及自包含 GLB，或者按 [本地目录导入](LOCAL-DIRECTORY-IMPORT.md) 在仓库外生成独立工作区。不要把任意源工程或原始资产包拖入网页期待自动解析，也不要运行资产包携带的程序。输入格式、ID 和资源限制见 [数据契约](DATA-CONTRACT.md)；授权与证据记录标准见 [资产接入标准](ASSET-INGESTION-STANDARD.md)。

真实浏览器、GPU、视觉及无障碍验收尚需在使用环境分别执行。遇到错误先保留备份和受影响条目 ID，勿通过改写验证布尔值掩盖缺失证据。验证边界见 [验证说明](VALIDATION.md)。
