# 公开范围与能力边界

本文件描述 AssetsPlatform 仓库中可独立运行的公开静态审阅器，供贡献者、部署者和资产目录维护者决定哪些代码及数据可以进入公开构建。运行入口为 `apps/reviewer/`；构建入口为根目录 `scripts/build-public.mjs`。

## 包含什么

公开构建只使用 `scripts/public-build-inputs.json` 明列的文件：标准自包含 GLB 与独立 2D 原图的目录读取、浏览器预览、本地审阅和备份、合成样例、语义候选的人工审阅及受控筛选。六种渲染预设是自行定义的通用**检视方式**，不是任何来源作品的专用视觉配方。动画示例是仓库生成的 glTF 轨道，播放状态与人工 WebGL 验证分别记录。

项目 ID、资源 ID 和数据集 ID 是输入目录的稳定身份；共享几何、材质或图片不自动证明两个物件具有同一语义。普通技术纹理不因像素是二维就成为独立 2D 物件。无证据保持未知；预览成功不等于资产完整、效果一致或可直接导入其他引擎。

## 不包含什么

此公开范围不分发来源工程、原始游戏资产、私人索引/存储收据、身份与受众配置、托管后台或特定工程的恢复和诊断分支。删除这些类别是为了让可运行代码的能力声明与实际授权范围一致；不能以改名、隐藏界面、保留死代码或免责声明代替移除。仓库不会调用外部模型、购买 API 额度、上传用户输入或执行资产包脚本。

后续若需要后台、账户、其他输入格式或工程专用转换，应先另定授权、数据来源和测试证据，并单独审查。当前源码不是这种能力的占位实现。

## 验证公开候选

1. 检查 `scripts/public-build-inputs.json` 的每个路径和所有相对 import，确认没有未授权文件被构建间接带入。
2. 运行 `node scripts/update-source-manifest.mjs`、`npm test`、`npm run build`、`npm run test:build`；重新扫描源码树和 `dist/reviewer` 中的专用标识、恢复路径与非合成资源。
3. 在受支持 WebGL 的浏览器按 [验证说明](VALIDATION.md) 检查实际界面、动画与 2D 状态；若未执行，标为未验证，不改动验证标记伪造通过。
4. 共享或公开导入产物前，另查其许可证、源路径、凭据、用户备注与模型 `extras`。自动测试不能代替数据拥有者授权。

此文只定义仓库的公开边界，不对任何外部资产、站点或账户做许可承诺。

## 公开范围整改：实际移除与通用替代

这次修改不仅包含六项界面/接入 issue，也收窄了公开源码范围。旧的专用参考实现没有通过改名、默认关闭或隐藏按钮保留在分发中。

| 原有类别 | 当前公开实现与回归入口 |
|---|---|
| 固定工程/实例诊断、特定来源依赖重连 | 从 `app.mjs` 删除这些执行分支；只消费目录显式关系、来源字段和通用 evidence section。目录/2D/语义回归验证通用流程 |
| 工程专属专题面板和动作流程 UI | 对应 HTML、CSS、事件及数据加载已移除；保留标准片段播放和一般来源审计。`public-scope.test.mjs` 核对全部字面 DOM 绑定 |
| 原引擎标量曲线、离线状态流程、专用镜头及材质规则 | 从 `viewer.mjs` 删除解释器和渲染分支；仅保留通用 glTF TRS、标准 LBS 蒙皮与 STEP/LINEAR/CUBICSPLINE 侧车。无法支持的旧输入明确拒绝，不隐式近似执行 |
| 特定工程调色配方 | `common-render-profiles.mjs` 重新定义六个自制通用检视预设；核心 ID 不接受目录覆盖，底层 mode 仅 material/clay/toon。模式存在、独立性和碰撞负例由自动测试检查 |
| 不可独立运行的固定托管参考 | 从候选源码树移除 `reference/hosted/`，不以残缺私有接线冒充通用后端。保留的[架构说明](ARCHITECTURE.md)描述实际可运行的静态平台；未来后台需独立设计、授权与验证 |

测试或文档中少量旧输入字段名称只用于拒绝负例和不支持格式说明，不对应可执行恢复实现。不得把这些否定性测试当成支持声明。真实 WebGL、平台权限与外部资产分类质量仍须单独验收。
