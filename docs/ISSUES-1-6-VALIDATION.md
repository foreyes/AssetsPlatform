# 静态审阅器 Issues 1–6 验收边界

本文概述公开静态审阅器中六项改动的可检查结果与剩余限制。编号对应 [AssetsPlatform 仓库 Issues #1–#6](https://github.com/foreyes/AssetsPlatform/issues)；它不是部署记录、真实资产分类评估或 issue 自动关闭依据，实际通过状态须以所检查提交的测试日志为准。功能与公开范围见 [产品手册](PRODUCT-MANUAL.md)、[公开范围](PUBLIC-SCOPE.md)。

| Issue | 可检查实现 | 不能由自动测试推出的结论 |
|---|---|---|
| #1 可移植测试 | 临时目录、符号链接排除、显式公开构建白名单与负例 | POSIX 测试不代表其他系统权限模型均已实测 |
| #2 自制动画接入 | 仓库生成的 1 秒 LINEAR glTF、CPU 采样、绑定和错误侧车负例；默认验证状态保持 pending | 未有人工 WebGL 证据时不得标记 ready；不代表任意动画格式已支持 |
| #3 GLB 内部依赖 | 可选索引 scene、node、mesh、primitive、material、texture 和内嵌 image，保留共享引用与内容摘要 | GLB 内部闭合不证明更早工程来源、外观或可运行行为 |
| #4 目录计数和范围 | 全目录、匹配、页的计数及当前筛选摘要分别计算；零结果与显式包含关系有回归 | 目录记录不保证几何或视觉完整 |
| #5 2D 状态 | 独立物件原图、缩略图、技术纹理和 3D 模型分别识别 | 图片能显示不等于授权、视觉或像素已验收 |
| #6 语义审阅 | 确定性事实、候选输入摘要、受控词表、人工决定与锁定、语义继承、分维度筛选和本地回滚；候选备份先预检再确认 | 不运行 AI，不产生真实目录标签准确率；未完成分类的误标/漏标/未知率评估 |

复审中特别验证了批量操作只作用于所选择的当前页、当前匹配集或当前数据集全目录；错误身份的导入和异步晚到文件不会改变当前侧车。锁定接受多个标签不会只保留最后一个；本地拒绝与更正优先于普通回导。这些结论来自合成数据和 DOM 替身测试，真实浏览器交互与存储配额另需按 [验证说明](VALIDATION.md) 检查。

运行入口：`npm test`、`npm run build`、`npm run test:build`。重新生成源码清单使用 `node scripts/update-source-manifest.mjs`，但不能以改写清单代替源码审查。测试全绿只能说明本仓库规定的自动断言通过；真实 GPU、授权和外部目录质量仍分别未知。
