# 分发范围与来源

本仓库不是原托管项目的镜像。apps/reviewer 是可独立运行的通用静态前端，使用自制示例。reference/hosted 是从现有实现按源文件类型与目录白名单提取的代码审阅材料，不含私有资产、生成清单、身份配置、运行状态或 Git 历史。

为避免公开真实资产指纹，参考源码中已识别的固定资产/存储摘要及具体 Entity 身份已替换为合成占位值；源码完整性摘要可能保留，它们不是资产数据。测试中的个人邮箱替换为合成地址。它们不是可用于生产读取的值；对应固定批次校验不可能用于恢复原私有数据。引用路径与模块关系保留。未修改生产代码。

参考源码缺少私有发布计划、部分 vendor/生成模块和原构建工具，存在有意未闭合的 import；不得将其描述为完整可编译后台。真正的独立托管版本需要配置化、可信认证、完整依赖许可和合成数据构建闭环。
