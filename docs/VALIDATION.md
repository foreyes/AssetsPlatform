# 验证说明与未验证项

本文说明 AssetsPlatform **公开静态审阅器**能用哪些证据支持声明，不能用哪些证据外推。需在仓库根目录执行；不涉及私人站点部署或外部工程。

## 自动检查

```sh
node scripts/update-source-manifest.mjs
npm test
npm run build
npm run test:build
```

`npm test` 包括目录与 ID 契约、JSON/GLB 预算、解析拒绝路径、合成模型和图片、语义候选/审阅/回滚、HTTP 本地服务与构建文件范围。`npm run build` 只生成 `dist/reviewer`，不是发布；`test:build` 核对显式白名单及确定性。若测试/源码清单不一致，先查实际文件变动，不通过删断言掩盖风险。

## 需要人工记录的检查

在支持 WebGL 的浏览器加载自行生成示例，记录浏览器版本、GPU 状态、目录 ID、实际看到的画面和失败情况。至少检查目录切换、搜索/分页、打开关闭详情、六个通用检视预设、无 WebGL、错误文件、图片原图与缩略图区分、审阅备份、语义候选接受/拒绝、批量页/匹配/全目录范围，以及切换数据集时旧异步结果不能出现。键盘、读屏与窄屏需独立观察；DOM 替身自动测试不能证明视觉/无障碍体验。

动画示例的 `ready` 必须有实际浏览器证据；仓库默认保留 `pending`，具体先人工核查再恢复基线的步骤见 [动画示例](ANIMATION-EXAMPLE.md)。仅 CPU 轨道/绑定通过不等于 GPU 播放或源引擎行为验证。

## 报告口径

每次报告标明测试命令、退出状态、输入版本、执行环境及没有执行的项目。`modelUrl`、缩略图或浏览器画面不能替代资产所有权、完整性、材质一致性或其他引擎兼容性证据。失败或不可用要写明原因和最小复现；未知不是“通过”，也不是“没有动画”。
